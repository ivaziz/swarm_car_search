## 1. Provenance & Authenticity Classification Matrix

Every image has been audited to determine its exact generation method and ground truth origin:

* **Genuine 2D Simulation Rendering**: Direct output from the Python simulation engine (`SwarmVisualizer` / Matplotlib).
* **Plot Generated from Real Data**: Matplotlib chart plotting empirically gathered numerical metrics.
* **Programmatically Rendered Graphic**: Manually composed visualization generated via Python script (NOT a native terminal capture).
* **Copied Historical Artifact**: Pre-existing output files found in `output/` prior to the audit session.
* **Unverified for 3D Gazebo**: 2D Matplotlib dashboards saved in Gazebo run folders that do not prove 3D Gazebo GUI execution.
